WEB DEMO — PLANTA DE BIODIÉSEL

Archivo principal: index.html

Publicar en GitHub Pages:
1. Crea un repositorio en GitHub, por ejemplo planta-biodiesel.
2. Sube index.html a la raíz del repositorio.
3. Entra en Settings > Pages.
4. En Build and deployment, elige Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y guarda.
6. Espera a que GitHub Pages publique la web y abre la URL que te muestre.

Notas antes de publicar para un cliente:
- La fotografía incluida es de archivo (2011), atribuida a Europa Press. Comprueba la licencia/permisos para uso comercial o sustitúyela por una foto autorizada por la empresa.
- Confirma la actividad, los datos técnicos y los contactos actuales con la empresa. La web evita presentar como actuales los datos históricos no verificados.
- El botón de contacto es provisional porque no se ha facilitado un correo oficial.
